Zo werkt het straks live:
1. Host maakt sessie
2. Vrijgezel en vrienden joinen met code
3. Host activeert vraag
4. Iedereen ziet live dezelfde reveal

Firebase invullen voor echte live modus

Vul bovenaan in de code jouw Firebase web config in bij FIREBASE_CONFIG. Host dit bestand daarna op GitHub Pages of Vercel. Dan kunnen host, vrijgezel en kijkers op verschillende toestellen live synchroniseren.
Nodig voor live: Firebase Authentication (anoniem is genoeg), Realtime Database of Firestore. Voor video’s die iedereen moet zien, upload je ze best naar Firebase Storage of gebruik je een gedeelde videolink.
